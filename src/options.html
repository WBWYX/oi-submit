OI Submit 选项

提交时若 OI Bench 面板里指定了语言，以面板的为准；这里配的是默认值。

连接

要和 VS Code 里 OI Bench 的 oiBench.router.port 一致，默认 27121。

默认语言

填的是语言名字里的一段文本，不是选项编号——AtCoder 的语言编号每场比赛都不一样， Codeforces 也会不定期加新编译器，按文本匹配才不会某天突然选错。 找不到匹配项时不会乱猜，会按页面当前选项提交并在结果里注明。

洛谷

只有洛谷有这个开关，别的平台没有 O2 这个概念。

Timus

Timus 没有登录态，Judge ID 就是凭据，在 作者信息页 能看到。只存在本机这个扩展里，不会发给任何人。

LibreOJ

LOJ 把编译选项拆成了四个下拉，其中 std 的默认值是 c++11，比别家低一大截—— 带 auto 返回值、结构化绑定的代码在洛谷交得好好的，到这儿直接 CE， 而人第一反应多半是去查自己的代码。留空表示不动页面上的选项。

提交方式

开着的话，扩展只负责把代码、语言、题号填进去并把提交按钮标出来，最后那一下由你点。 交出去之后照样回传评测结果。关掉则填完直接替你点。

评测结果

关掉的话提交发出去就算完，结果自己看页面。
